# Inbox folder

**Inbox folder.** An optional watched folder, off until the user turns it on under Account, `Documents/nvoke/inbox` unless they pick another (Change opens a native folder picker in main, a drive root is refused; Open shows it). Main (`src/main/inbox.ts`) looks at it every 2 seconds for .csv, .tsv and .txt files (not hidden files, `~$` locks, partial downloads or `.nvoke.csv` copies) and takes a file on the second look that sees the same size and modified time, so a copy in progress is left alone. A file whose enriched copy is already in the done folder is skipped, a file over 5 MB gets a notification, and files wait with a notification while nobody is signed in and are taken at the next sign-in. Main reads the file and pushes it to the renderer (`inbox:file`, with an opaque id, never a path), which enriches it like the CSV drop with the guessed column, cut to the lower of the search limit and what is left of this month's allowance (`/v1/me`): `usage.emailsLimit - usage.emailsVerified`, none left means a quota notification. When the search is done the renderer sends the CSV back (`inbox:done`); main writes `name.nvoke.csv` to the done folder (`nvoke/done` beside an inbox called `inbox`, else `done` inside the chosen folder), moves the original to `done/originals` (renamed `name (2).csv` when taken) and shows a native notification, whose click shows the file. A failed search, an empty column or a quota error (`inbox:failed`) is a notification and the file stays in the inbox until it changes. It runs while the window is hidden in the tray, as long as the app is signed in.
