# Grab from screen

**Grab from screen**: a row in the quick window ("Grab from screen", found by typing grab, scan, ocr or exhibitors) turns a company list on screen into a domains search: a conference exhibitor list, a PDF, a directory, a LinkedIn company list. The quick window hides, main captures the display under the pointer once with `desktopCapturer` and opens a full screen overlay on it (`#/grab` of the same renderer, `components/GrabOverlay.tsx`) that paints that frozen frame, dims it and lets the user drag a box (Esc, a right click or a click without a drag cancels). Main crops the box (doubled when it is narrow), reads it with the OS text engine (`src/main/ocr.ts`): Windows.Media.Ocr through Windows PowerShell on Windows (words with positions, so a table row splits into columns at wide gaps), the Vision framework through JavaScript for Automation (`osascript -l JavaScript`) on macOS, and the `tesseract` command on Linux when installed. Nothing is bundled (tesseract.js was left out for its size and because the packaged app ships no `node_modules`) and nothing goes over the network: the image lives in main, the overlay gets it only to paint, and the crop is a temp file deleted after the read. `src/main/grab-extract.ts` keeps the companies: domains from domains, URLs and work addresses, and lines that read as company names, dropping headers, buttons, booth codes, countries, counts and prose. People never leave main: a personal address (gmail and the like), a line that reads as a person's name (a common first name plus capitalized words, no legal form) or a job title is dropped and only counted; "Head of Sales at Acme" keeps Acme. The quick window comes back with "Reading the box", then the list (`components/GrabPanel.tsx`): each row can be fixed, unticked or removed, more can be added, "N people left out" shows the count, and Find contacts at N (Cmd or Ctrl Enter) starts a `domains` search on the ticked rows (up to 1,000) and shows its progress like any quick search. macOS needs Screen Recording: when it is not granted the first grab asks once (which registers nvoke in the list) and the window says to allow it, with Open System Settings, then quit and reopen nvoke. No text engine (Linux without tesseract, Windows without an OCR language) and an empty box get their own message and Grab again. Channels: `grab:start` and `grab:open-settings` (quick window only), `grab:get-frame`, `grab:select` (a box in CSS px, validated) and `grab:cancel` (overlay only), and `grab:state` (main to the quick window: `reading`, `done` with items and the people count, or `error` with a reason).
