# Free tools

Acquisition pages on nvoke.run/tools, each backed by a public route under `/v1/tools` (`src/api/routes/tools.ts`, schemas in `packages/shared/src/tools.ts`). No sign-in; every result ends in "Start free".

- **Email verifier** (`/tools/email-verifier`, `POST /v1/tools/verify-email`). The pipeline's verifier, run in the API. Port 25 is shared with the worker on the same VPS and Hostinger throttles it past about 5 connections a minute, so the tools get their own share, `TOOLS_SMTP_PROBES_PER_MINUTE` (default 1), which the worker gives up (`workerProbesPerMinute`). On top of that a daily cap of 300 probes. Past either, or for an opted-out address, the answer comes from syntax, disposable lists and MX only and says `depth: domain` ("sign up for the full check"). Results read and write the shared `email_checks` cache (30 days, 1 day for unknown).
- **Website email extractor** (`/tools/website-email-extractor`, `POST /v1/tools/extract-emails`). One domain, the pipeline crawler at 6 pages and 25 seconds, robots.txt on every hop, every fetch refused when the host resolves to a private address. An opted-out domain is not read (`opted_out`); opted-out addresses are dropped. Answers from the shared crawl cache when it is fresh and writes a fresh crawl back to it. Anonymous users see only generic role addresses; addresses of people are a count (`hiddenPersonal`). At most 3 crawls at once and 300 a day.
- **SPF and DMARC checker** (`/tools/spf-dmarc-checker`, `POST /v1/tools/email-auth`). DNS only: MX, SPF (one record, the `all` qualifier, lookups counted through includes against the limit of 10), DMARC (policy, `rua`, `pct`) and DKIM under common selectors, each graded pass, warn or fail.
- **Limits.** Per client IP an hour: 10 verifications, 5 extractions, 30 DNS checks (429 `rate_limited`). Daily caps answer 429 `busy`. Counters are in memory in the one API process. With `TURNSTILE_SECRET_KEY` set (and `NEXT_PUBLIC_TURNSTILE_SITE_KEY` on the site) the verifier and extractor also need a Turnstile token (403 `captcha_failed`).
