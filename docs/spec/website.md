# Website (nvoke.run)

Landing page whose every call to action is "Start free" (`/sign-up`, then the web app), with nvoke Desktop as the premium native app, `/agents` (the API, MCP and agent sign-up), `/docs` (quickstart, `/docs/api` rendered from the catalog, `/docs/mcp`, `/docs/agents`), `/claim` (an agent-created account's owner takes it over; Clerk, like `/desktop`), `/llms.txt` and `/agents.md` (generated from the catalog for agents), pricing (one slider over the plan ladder, no feature grid), a `/desktop/billing` page for checkout, `/download` as the nvoke Desktop page (Windows, macOS, Linux from the latest GitHub Release, plus what the app adds), `/bot` page explaining nvokebot and how to block or opt out, `/opt-out` (address or whole domain, calls `POST /v1/privacy/opt-out`), `/tools` (free email verifier, website email extractor and SPF and DMARC checker, see [Free tools](free-tools.md)), `/privacy` in Danish and English including the Article 14 notice for people whose addresses we collect, and `/terms` with the customer duties listed under [Privacy](privacy.md).
