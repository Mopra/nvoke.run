# Openers

One drafted first line per company, for the user to copy or export. nvoke never sends. Code in `apps/server/src/openers`, route in `src/api/routes/leads.ts`, schemas (`Opener`, `DraftOpenersRequest`, `DraftOpenersResponse`) in `packages/shared/src/leads.ts`.

- **Ask.** `POST /v1/searches/:id/openers` with `companyIds` (some companies) or none (the whole search). Only companies with at least one valid, unsuppressed address qualify, so the work follows the verified emails the plan pays for. Without `redo`, a company with an opener (`done`, `none`) or one `queued` is skipped; `failed` is asked again. With `redo`, everything but `queued` is drafted again. Returns 202 `{ queued, skipped }` (skipped: asked for but not queued). 503 `ai_unavailable` when Claude is not configured or the account spent its monthly Claude budget (`src/ai/usage.ts`); 404 for another user's search. The companies turn `queued` at once and the route queues one `opener` job per 8 (`OPENER_BATCH`), without a search id, so openers never hold a running search open and cancel leaves them be.
- **Draft.** The worker's `opener` job (`runOpener`, a quarter of the worker's slots, 3 minutes) reads the companies' kept page text (`domain_pages`). A company without kept text (a cached crawl from before openers, or a site only the desktop could read) is `none` without a call. The rest go to Claude in one structured call (`bulk` tier, Haiku, task `opener`) with the account's site profile (name, what they do, offer, audience, proof) as the sender when there is one, else "write about the company only". Each company is keyed `c1`, `c2` ... in the prompt.
- **No invented facts.** Claude answers per key with `line`, `quote` (the words on the page the line rests on, copied exactly) and `sourceUrl`. The line is kept only when the quote, matched without case, spacing or typographic quotes, is on that page's title, description or text, the page is one of the company's, the quote is 12 to 300 characters and the line is at most 300 characters with no merge tags or placeholders (`{{...}}`, `[...]`, `<...>`, `%NAME%`, "first name"). Dashes used as punctuation become commas. Anything else is `none`. The prompt also forbids greetings, names of people, praise and claims about the sender beyond the profile, and writes in the language of the company's pages.
- **Store and show.** `done` stores the line, quote and source URL on the company row. A Claude failure (`AiError`: refusal, no or invalid output, budget spent) marks the batch `failed` at once; other errors retry the job, and a job that gives up marks its companies `failed`. `GET /v1/searches/:id/companies` returns `opener` on each company (`null` until asked), the CSV has the `opener` column, `lead.ready` webhooks carry it, and the MCP tool `draft_openers` asks for them.
- **Screens.** The web app and the desktop show the line under the company with Copy and a "from /page" link to the source (the quote on hover), "Draft openers" and "Draft openers again" in the search's menu, and refresh while any opener is `queued`. The desktop also drafts for the selected rows; the web app per row.
