# Changelog

What changed in each desktop release, newest first. The app shows the
sections the user has not seen yet on the first start after an update, and the
release workflow uses the section as the GitHub release notes. One `## x.y.z`
heading per version, then a short bullet per change, written for the user.

## 0.1.0

- First public build. Search by place and keyword, or paste a list of domains.
- nvoke now updates itself. New versions download in the background and install on the next restart, or quietly while nvoke sits in the tray.
- This card shows what changed, once, after each update.
