# Changelog

What changed in each desktop release, newest first. The app shows the
sections the user has not seen yet on the first start after an update, and the
release workflow uses the section as the GitHub release notes. One `## x.y.z`
heading per version, then a short bullet per change, written for the user.

## 0.1.2

- Remove your website from Searches: the row's menu and the website page both have Remove. Searches you started from it stay.
- A search now shows a working scene while it finds its first leads, and results stream in live.

## 0.1.1

- Describe your customer in plain words and nvoke plans the searches itself. Or start from your own website.
- Search more into the same list, and results show the people first.
- Fixed a blank window on start when your account had a search this version did not know.
- Installing is one click now, and the first start says hello.

## 0.1.0

- First public build. Search by place and keyword, or paste a list of domains.
- nvoke now updates itself. New versions download in the background and install on the next restart, or quietly while nvoke sits in the tray.
- This card shows what changed, once, after each update.
